# 后续任务与验收标准

## 当前阶段结论

P0 已可运行，P1 第一批已经形成基本闭环。下一轮重点不再是“把页面先摆出来”，而是做真机验证、结果沉淀和真实同步。

## P1 剩余补强

### 1. 朗读模式补强

任务：

- 接入示例音频播放和跟读节奏提示
- 将录音文件路径与朗读结果进一步沉淀
- 补朗读完成页

验收：

- 可从详情页进入朗读
- 可播放示例音频
- 可完成一轮朗读并看到汇总结果

### 2. 背诵模式补强

任务：

- 增加整首完成页
- 增加每句评分汇总
- 增加继续巩固入口

验收：

- 可逐句背诵
- 可看到整轮背诵结果
- 可保存整次背诵记录

### 3. 测评历史沉淀

任务：

- 增加测评历史卡片或历史页
- 将测评结果沉淀到“我的”

验收：

- 可查看最近测评结果
- 可看到总分、正确率和建议

### 4. 错题本增强

任务：

- 增加按错题批量再练
- 增加按诗词维度筛选

验收：

- 可批量重练当前筛选范围内错题
- 可快速回到对应诗词或练习入口

## 同步与云准备

### 1. 远端 API 接口化

任务：

- 将 `CloudSyncApi` 从占位实现替换为真实 HTTP API
- 建立 push / pull / conflict preview 接口
- 预留鉴权和设备标识

验收：

- 可完成一次非阻塞 push
- 可完成一次非阻塞 pull
- 可拿到服务端能力声明

### 2. 本地 ack 回写

任务：

- 远端确认成功后，把本地 `sync_status` 从 `pending_push` 回写为 `synced`
- 更新 `revision_token`
- 刷新 checkpoint

验收：

- 同步成功后本地 pending 数量下降
- 下次同步不会重复推送同一批已确认记录

### 3. 冲突解决落地

任务：

- 将文档中的资源级策略写进实际同步流程
- 区分 `last-write-wins`、`append-only`、`soft delete`
- 为复杂冲突保留服务端建议合并结果

验收：

- 不同资源能按策略处理冲突
- 产生冲突时可输出结构化报告
- 不阻塞 P0/P1 本地主链路
