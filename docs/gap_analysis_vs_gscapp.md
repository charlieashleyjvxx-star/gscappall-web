# GSCAPPALL 与旧项目 GSCapp 差距分析

更新时间：2026-05-25

## 对照范围

旧项目：`D:\GSCapp\gushici-app`

新项目：`D:\GSCAPPALL`

本分析不按“是否有页面文件”判断迁移完成度，而按产品闭环判断：

- 已迁移：主流程可用，数据、规则、记录和回流基本闭环。
- 部分迁移：已有页面或基础能力，但仍缺规则、统计、报告、数据沉淀或自动化验证。
- 未迁移：旧项目已有明确能力，新项目当前还没有对应实现。

## 已基本追平的能力

- 诗词基础数据：标题、作者、朝代、年级、分类、原文、拼音、注释、译文、赏析等字段已进入 seed 和本地数据库。
- 主导航与核心页面：首页、诗词库、诗词详情、我的、收藏、每日诗、学习卡、游戏入口已可运行。
- 学习闭环第一版：朗读、背诵、听写、测评、报告、错题本、错题重练已有主流程。
- 多资料能力：本地资料创建、切换、编辑、数据隔离已做多轮专项修复和测试覆盖。
- 成长体系：成长面板、积分、徽章、周/月报告、家长摘要已有第一版。
- P3 游戏闭环：诗词接龙、飞花令、闯关地图、章节详情、奖励记录、成绩回流和成长报告联动已落地。
- 同步层：profile 维度、sync payload、applyRemoteEnvelope、冲突策略、同步日志、HTTP transport 和 sync-proxy 骨架已推进。
- Android 回归：已拆出稳定短入口和多个专项脚本，并完成多次真机归档验证。

## 仍存在的主要差距

### 1. 语音正式评测

旧项目有本地启发式评分，新项目已明确不再把当前离线识别作为正式评分依据。

当前状态：

- `sherpa_onnx` 保留为离线辅助识别。
- 正式评分接口已抽象为 `SpeechAssessmentProvider`。
- Mock Provider 已接入朗读/背诵页面。

剩余工作：

- 等厂商账号和密钥。
- 接真实云评测 Provider。
- 用 10 条真实朗读音频跑 POC，确认分数稳定后替换 Mock。

### 2. 真实云同步生产化

旧项目主要是本地形态，新项目同步目标更大，但仍未完全生产化。

当前状态：

- 本地 payload、远端 envelope、profile scope、冲突策略已覆盖主要资源。
- sync-proxy 已有 mock/formal 服务端，SQLite/Postgres adapter 已对齐同一 store 接口。
- Flutter HTTP transport 已有鉴权 header 和 device id 方向。

剩余工作：

- 当前内置账号注册/登录、token 刷新/注销和 profile grant 表可用于联调；后续需替换为真实生产身份源。
- Postgres adapter 已可运行，后续重点是部署环境、迁移策略和备份恢复。
- 服务端请求日志、限流、access token 清理和批量大小保护已落地，后续接生产观测。
- 多设备全资源压力测试已进入 smoke，后续需要常态化接入 CI/发布验证。

### 3. iOS 真机验证

当前仍缺 macOS + Xcode 环境下的真实构建、权限和通知验证。

剩余工作：

- iOS 首次真机构建。
- 麦克风、语音识别、通知权限验证。
- iOS 朗读/录音/回放链路验证。

### 4. 学习体验细节

新项目已覆盖主流程，但部分体验还可继续追旧项目成熟度。

建议继续补强：

- 每日诗历史、复习、连续打卡和积分解释。
- 学习卡筛选、自测、笔记预览、复习间隔说明。
- 听写难度、填空/全文模式、逐句练习、提示和错字分析。
- 测评首页、历史报告、报告详情、弱项统计和分数段聚合。
- 错题本按模式、错题类型、知识点、关卡聚合与重练入口。

### 5. P3/P4 游戏化与成长报告

新项目已经反超旧项目的一部分结构化能力，但仍可继续精修。

建议继续补强：

- 闯关地图更多路线和章节视觉。
- 章节详情推荐练习、历史筛选、奖励明细和最近推进记录。
- 飞花令/诗词接龙成绩回流动效和原因解释。
- 成长报告关卡趋势、贡献标签、趋势点明细和家长视角说明。

## 当前优先级建议

1. 稳定性：继续保持 `flutter analyze`、`flutter test`、Android 短入口回归绿色。
2. 同步生产化：真实账号服务接入、Postgres 部署验证、profile 授权运营化和全资源压力测试常态化。
3. P3/P4 体验：闯关地图章节详情、成长报告趋势、来源提示、返回定位。
4. 语音正式评测：等待厂商账号后接真实 Provider 并跑音频 POC。
5. iOS：有 macOS 环境后做首次真机专项。

Worker A：稳定性与多资料隔离。

Worker B：每日诗、学习卡和成长体验。

Worker C：测评、听写、错题本和报告中心。

Worker D：同步层、Android 回归和脚本文档。

Worker E：P3/P4 游戏化体验和成长报告联动。
