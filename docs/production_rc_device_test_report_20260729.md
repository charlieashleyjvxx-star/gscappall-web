## 4. 缺陷与闭环

### RC-BOOT-001：全新安装初始化失败

- 严重级别：P0 / Release Blocker
- 首轮现象：首次启动停留在“初始化失败”，提示“当前版本暂不支持网络备份”。
- 根因：本地诗词种子首次导入完成后无条件调用远端上传；禁用网络备份改为显式失败后，该异常被传播到应用启动流程。
- 修复：仅在网络备份已配置启用时触发种子导入后的上传。正式同步入口仍保持禁用即失败，不返回占位成功。
- 回归测试：新增“网络备份关闭时本地种子导入成功”自动化用例；同步专项 11 项通过。
- 复验：重新构建、卸载正式包、全新安装后冷启动进入首页，结果通过。

## 6. 尚未覆盖与发布前反馈

以下项目不影响本轮 APK 真机安装结论，但正式对外发布前仍需执行：

1. 上传 AAB 至 Play Console 内部测试轨道，验证 App Signing、设备拆分安装和旧版本升级。
2. 在真实备份服务配置下验证登录、上传、取回、冲突处理和弱网/超时文案。
3. 由人工佩戴耳机或在安静环境确认录音实际音质、回放音量和长录音稳定性；本轮自动验收确认了权限、录音文件生成和回放控件启用。
